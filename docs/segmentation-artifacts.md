# Scene Segmentation Artifacts

Each input below `data/scene` receives a stable path-derived scene ID and writes to `data/work/<scene-id>/segmentation`.

## Coordinates and cameras

Geometry uses Blender world coordinates after evaluated object and instance transforms. Units are Blender units unless `geometry.meters_per_blender_unit` is explicitly configured. The implementation does not infer scale from bounds.

Camera JSON stores row-major 4x4 `camera_to_world` and `world_to_camera` matrices. Blender cameras look along local `-Z` with local `+Y` upward. Pixel coordinates use origin at the upper-left and pixel centers at `(column + 0.5, row + 0.5)`. Compositor Z pass values are interpreted as metric ray distance from the camera center.

## Geometry

`geometry/geometry.npz`:

- `vertices`: float32 `[V, 3]` world positions.
- `triangles`: int64 `[F, 3]` indices into vertices.
- `triangle_rgb`: uint8 `[F, 3]` material fallback colors.
- `triangle_corner_rgb`: uint8 `[F, 3, 3]` UV texture samples at triangle corners, with material fallback.
- `triangle_object`: int32 `[F]` evaluated object IDs.
- `triangle_polygon`: int32 `[F]` source polygon IDs.
- `object_names`: Unicode `[O]` source object names.

`geometry/samples.npz`:

- `points`: float32 `[N, 3]` area-weighted surface samples.
- `colors`: uint8 `[N, 3]` sampled/fallback color.
- `normals`: float32 `[N, 3]` face normals.
- `triangle_ids`: int64 `[N]` source evaluated triangle IDs.
- `barycentric`: float32 `[N, 3]` triangle coordinates.

## Views and SAM3

`views/cameras/<view-id>.json` records image dimensions, intrinsics, both camera transforms, and relative RGB/depth paths. RGB images are PNG. Depth images are 32-bit OpenEXR files generated by the Blender compositor.

`sam3/masks.json` contains canonical class IDs, prompts, confidence, XYXY boxes, dimensions, and column-major uncompressed RLE masks.

## Mosaic3D and fusion

`mosaic3d/semantic_scores.npz`:

- `class_ids`: int32 `[N, K]` canonical top-k IDs.
- `confidence`: float32 `[N, K]` normalized confidence.
- `unknown`: bool `[N]` confidence/margin rejection.

`fusion/point_labels.npz`:

- `points`: float32 `[N, 3]`.
- `semantic_ids`: int32 `[N]`; `-1` means unknown.
- `semantic_confidence`: float32 `[N]`.
- `instance_ids`: int32 `[N]`; `-1` means no thing instance.
- `triangle_ids`: int64 `[N]`.
- `unknown`: bool `[N]`.
- `visibility_count`: int32 `[N]`, number of depth views observing the point.
- `is_observed`: bool `[N]`.
- `is_core`: bool `[N]`; always true for legacy whole-scene runs.

`fusion/face_labels.npz` contains `semantic_ids`, `semantic_confidence`, `instance_ids`, `visibility_count`, `is_observed`, and `is_core` for the evaluated triangles. `fusion/fused_instances.npz` is the restart artifact used by the export stage. `fusion/instances.json` contains compact point/face index runs, class and confidence, observing views, visible/core point ratios, centroid, AABB, and PCA OBB.

## Restart behavior

`manifest.json` records each stage as `pending`, `running`, `complete`, or `failed`. Resume requires matching stage configuration and upstream artifact digests. `--force-stage <name>` invalidates that stage and every stage after it. A batch summary is written to `data/work/segmentation_summary.json`.
